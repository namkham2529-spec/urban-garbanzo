# tools/ — สคริปต์ตั้งค่า

## `registration-backend.gs` — ระบบรับลงทะเบียนนักกีฬา → Google ชีต

ฟอร์มลงทะเบียน **อยู่ในเว็บ** (หน้า `register.html`) ออกแบบตามโทนบุรีรัมย์ลีก
สคริปต์นี้เป็น "หลังบ้าน" ที่รับข้อมูลจากฟอร์มมาบันทึกลง Google ชีต
หัวคอลัมน์ตรงกับชีต **'ทะเบียนนักกีฬา'** ในไฟล์กลาง และตรงกับที่หน้า `id-cards.html` อ่าน

### ติดตั้ง (ครั้งเดียว)

1. เปิด <https://script.google.com> → **โปรเจกต์ใหม่** → วางเนื้อหา `registration-backend.gs` ทั้งหมด → บันทึก
2. **Deploy → New deployment → ชนิด "Web app"**
   - Execute as: **Me**
   - Who has access: **Anyone**
   - → Deploy → อนุญาตสิทธิ์ → คัดลอก **Web app URL** (ลงท้าย `/exec`)
3. วาง URL นั้นที่ **`config.registerEndpoint`** ใน `assets/js/data.js`
   → ฟอร์มในหน้า `register.html` จะเริ่มส่งข้อมูลเข้าชีตทันที
4. เปิด URL `/exec` ในเบราว์เซอร์ 1 ครั้ง — จะสร้างชีต "BLA 2026 — ทะเบียนนักกีฬา (จากเว็บ)"
   และแสดง **ลิงก์ CSV** (เอาไปวางที่ `config.athleteSheetCsvUrl` สำหรับหน้าออกบัตร)

### แก้โค้ดภายหลัง

ต้อง redeploy: **Deploy → Manage deployments → ✏️ Edit → Version: New version → Deploy**
(URL `/exec` เดิมใช้ได้ต่อ)

### คอลัมน์ในชีต

`ประทับเวลา · ชื่อสโมสร · รุ่นอายุ · ชื่อ-นามสกุลนักกีฬา · วันเดือนปีเกิด · เลขบัตร ปชช./เลขนักเรียน · เบอร์เสื้อ · ชื่อผู้ปกครอง · เบอร์ติดต่อผู้ปกครอง · ลิงก์รูปถ่ายนักกีฬา`

### รูปถ่ายนักกีฬา (บังคับอัปโหลดในฟอร์ม)

ฟอร์มมีช่อง **อัปโหลดรูปถ่ายหน้าตรง** (บังคับ) — เบราว์เซอร์ย่อรูปให้เล็กลงก่อนส่ง สคริปต์จะ:
1. ถอดรหัสรูปแล้วบันทึกเป็นไฟล์ในโฟลเดอร์ Drive ชื่อ **"BLA 2026 - รูปถ่ายนักกีฬา"** (สร้างให้อัตโนมัติครั้งแรก)
2. ตั้งสิทธิ์แชร์เป็น "ทุกคนที่มีลิงก์ · ผู้อ่าน" ให้อัตโนมัติ
3. บันทึกลิงก์รูปลงคอลัมน์ **ลิงก์รูปถ่ายนักกีฬา** — หน้าออกบัตรอ่านลิงก์นี้ไปแสดงผลได้ทันที

> ฟีเจอร์นี้ต้องใช้สิทธิ์ Google Drive เพิ่ม — ตอน redeploy โค้ดเวอร์ชันใหม่ครั้งแรก ระบบจะขออนุญาตเพิ่ม กด **Allow** อีกครั้ง

> ทางเลือก: ถ้าอยากใช้ **Google Form** แทนฟอร์มในเว็บ ให้สร้างฟอร์มเอง (ตั้งชื่อคำถาม = ชื่อคอลัมน์ข้างบน)
> แล้ววางลิงก์ embed ที่ `config.registerFormUrl` — หน้า register จะแสดง Google Form แทน
