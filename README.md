# บุรีรัมย์ลีก อะคาเดมี่ — เว็บไซต์รายการ

เว็บไซต์ลีกฟุตบอลเยาวชน **บุรีรัมย์ลีก อะคาเดมี่ (Buriram League Academy)**
สแตติกล้วน ไม่มีขั้นตอน build · โทนตามตราสัญลักษณ์ (กรมท่า + ฟ้า + ส้มอิฐ + ทอง)
แรงบันดาลใจจากเว็บไทยลีก (thaileague.co.th)

## หน้าเว็บ

| ไฟล์ | เนื้อหา |
|---|---|
| `index.html` | ฮีโร่ · ตัวเลขลีก · โปรแกรมสัปดาห์เปิดฤดูกาล · ทำเนียบสโมสร · ที่มา · CTA ลงทะเบียน |
| `clubs.html` | **ทำเนียบสโมสร** — โลโก้ 12 ทีม แตะเพื่อไปเฟซบุ๊กของแต่ละสโมสร + รายละเอียด + ตัวกรอง |
| `schedule.html` | โปรแกรม 11 สัปดาห์ · รอบละ 6 คู่ · **ระบุสนามแข่ง** · ยังไม่ใส่วันที่ (รอประกาศ) |
| `standings.html` | **ตารางคะแนน** แยกรุ่นอายุ (U8/U10/U12/U14) — คำนวณอัตโนมัติจากผลการแข่งขัน |
| `results.html` | **ผลการแข่งขัน** แยกรุ่นอายุและสัปดาห์ |
| `history.html` | ประวัติ + คณะก่อตั้ง (2567 → 2568 → 2569) |
| `register.html` | **ลงทะเบียนนักกีฬา** — ฝัง Google Form (นักกีฬากรอกเอง → เข้า Google ชีต) + คู่มือตั้งค่า |
| `id-cards.html` | **ออกบัตรประจำตัวนักกีฬา** — วาง/อัปโหลด CSV จากชีต → สร้างบัตรทุกคน แยกสีตามรุ่น + สั่งพิมพ์ |
| `about.html` | วัตถุประสงค์ · รูปแบบการแข่งขัน · คณะผู้จัด/ติดต่อ |
| `promo.html` | วิดีโอโปรโมตแบบเล่นอัตโนมัติ (ไฟล์เดี่ยว มีเสียงในตัว) |

## ปรับข้อมูล — แก้ที่ `assets/js/data.js` ที่เดียว

- `config.registerFormUrl` — ลิงก์ embed ของ Google Form ลงทะเบียน (วางแล้วฟอร์มจะขึ้นในหน้า register)
- `config.athleteSheetCsvUrl` — ลิงก์ CSV ของชีตทะเบียนนักกีฬา (ถ้าจะให้หน้า id-cards มีปุ่มดึงอัตโนมัติ)
- `teams[].fb` — ลิงก์เฟซบุ๊กของแต่ละสโมสร (ตอนนี้มีแค่ กองฟาง ยูไนเต็ด — ที่เหลือรอลิงก์)
- `results` — บันทึกผลการแข่งขัน `{ round, ageGroup:"U12", home, away, hs, as }` → ตารางคะแนน/ผลอัปเดตทันที
- `schedule` — โปรแกรม 66 คู่ พร้อมวันที่จริง + สนาม (อ้างอิงไฟล์กลาง BLA 2026: เริ่ม 4 ต.ค. 2569 · จบ 7 มี.ค. 2570 · นัดที่ 6 และนัดปิดฤดูกาลที่สนามกลาง)
- `cardThemes` — สีบัตรแต่ละรุ่น: **U8 เขียว · U10 น้ำเงิน · U12 ฟ้า · U14 ชมพู** (ผสมโทนกรมท่าของโลโก้)

`data/*.json` เป็นสำเนาไว้ให้ระบบอื่นนำไปใช้ (ตัวจริงคือ `data.js`)

## ระบบลงทะเบียน → บัตรประจำตัว (ทำงานกับ Google ชีต)

1. สร้าง **Google Form** ใส่คำถามตามหัวข้อในหน้า `register.html` แล้วกด “ลิงก์กับ Google ชีต”
2. ในฟอร์ม → **ส่ง → `<>` ฝัง HTML** → คัดลอกค่า `src` ของ `iframe` → วางที่ `config.registerFormUrl`
3. เมื่อมีคนลงทะเบียน เปิดชีต → **ไฟล์ → ดาวน์โหลด → CSV**
4. เปิด `id-cards.html` → วาง/อัปโหลด CSV → กด “สร้างบัตร” → กรองรุ่นอายุ → **พิมพ์ / บันทึกเป็น PDF**

ชื่อคอลัมน์ที่ระบบอ่านได้ (ยืดหยุ่น จับคู่จากคำใกล้เคียงได้): `ชื่อ-สกุล`, `สโมสร`, `รุ่นอายุ`, `วันเกิด`, `หมายเลข`, `ตำแหน่ง`, `เลขบัตรประชาชน`/`รหัสนักกีฬา`, `ลิงก์รูป`

> ข้อมูล CSV ประมวลผลในเบราว์เซอร์ทั้งหมด ไม่ถูกส่งออกไปที่ใด

## รันพรีวิว

```
PowerShell -ExecutionPolicy Bypass -File serve.ps1
```
เปิด http://127.0.0.1:8080 — หรือเปิดไฟล์ตรง ๆ ด้วย `file://` ก็ได้ (ข้อมูลฝังผ่าน `data.js` ไม่ใช้ fetch)

## Deploy

`netlify.toml` ตั้ง `publish = "."` — ลากทั้งโฟลเดอร์ขึ้น Netlify ได้เลย ไม่มีขั้นตอน build

## ตั้งค่าระบบลงทะเบียนนักกีฬา

ฟอร์มลงทะเบียน**อยู่ในเว็บ** (`register.html`) — ส่งข้อมูลผ่าน Apps Script ไปลง Google ชีต

1. Deploy **`tools/registration-backend.gs`** เป็น Web app (Execute as: Me · Access: Anyone)
2. วาง URL `/exec` ที่ **`config.registerEndpoint`** ใน `assets/js/data.js`
3. เปิด `/exec` 1 ครั้ง → ได้ลิงก์ CSV ของชีต → วางที่ `config.athleteSheetCsvUrl`

รายละเอียดใน `tools/README.md` · ทางเลือก: ใช้ Google Form ผ่าน `config.registerFormUrl`

## ระบบ ↔ ไฟล์กลาง (Google ชีต)

หน้าลงทะเบียน + ออกบัตร ออกแบบให้ตรงกับชีต **'ทะเบียนนักกีฬา'** ในไฟล์กลาง BLA 2026
(คอลัมน์: ชื่อสโมสร · รุ่นอายุ · ชื่อ-นามสกุลนักกีฬา · วันเดือนปีเกิด · เลขบัตร ปชช./เลขนักเรียน · เบอร์เสื้อ · ชื่อผู้ปกครอง · เบอร์ติดต่อผู้ปกครอง)
ดาวน์โหลดชีตนั้นเป็น CSV แล้ววางที่หน้า **ออกบัตรประจำตัวนักกีฬา** ได้ทันที
